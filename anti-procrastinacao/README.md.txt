# 🎯 Anti-Procrastinação

Planejador de metas inteligente que combate a procrastinação através de gamificação e acompanhamento de progresso.

## 🚀 Funcionalidades

- ⏱️ Timer integrado para medir tempo dedicado
- 📊 Múltiplas barras de progresso (horas, dias, meta diária)
- 🔥 Sistema de streak (dias consecutivos)
- 💰 Conversão de tempo em valor monetário
- 📅 Calendário com data de início
- ⚠️ Alertas de meta diária
- 💾 Salvamento automático (LocalStorage)
- 📱 PWA - Instalável no celular/desktop

## 📥 Como Usar

1. Acesse o site
2. Clique em "+ Nova Meta"
3. Preencha os dados da sua meta
4. Clique em "Começar" para iniciar o timer
5. Trabalhe na sua meta!

## 💻 Tecnologias

- React 18
- Tailwind CSS
- LocalStorage
- PWA (Progressive Web App)

## 📱 Instalar como App

### Android/Chrome:
Menu (⋮) → "Adicionar à tela inicial"

### iPhone/Safari:
Compartilhar (□↑) → "Adicionar à Tela Inicial"

## 🔐 Privacidade

Todos os dados são salvos localmente no seu navegador. Nenhuma informação é enviada para servidores externos.
